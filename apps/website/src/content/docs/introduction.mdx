**Devicons** is an open-source, production-ready icon set built for developers. Every icon is available as a colored brand mark and a monochrome glyph, shipped as clean SVGs, an icon font, and first-class framework components.

## Why Devicons

- **Premium crisp icons** — brands, languages, frameworks, cloud services, and tooling.
- **Two variants** — full-color brand marks and monochrome glyphs
- **Multiple formats** — raw SVG, icon font with CSS classes, sprites, and React / Vue / Svelte packages.
- **Zero runtime cost** — tree-shakeable imports, no runtime fetches, no hidden bundles.
- **MIT licensed**

## Philosophy

Devicons is opinionated on purpose. The entire set follows a unified grid, optical weight, and corner language so any two icons read as siblings — not strangers pulled from different packs.

> Your UI should feel intentional. The icons you ship in it should feel intentional too.
