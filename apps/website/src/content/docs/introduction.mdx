Devicons started as a web font used by millions of developers. Now it ships as native packages for React, Vue, and Svelte too.

## Why Devicons

- Crisp icons for brands, languages, frameworks, cloud services, and tooling
- Full-color brand marks and monochrome glyphs for every icon
- Raw SVG, icon font, sprites, and framework-native components
- Tree-shakeable imports with no runtime fetches or hidden bundles
- MIT licensed

## Philosophy

The entire set follows a unified grid, optical weight, and corner language. Any two icons should read as siblings, not strangers pulled from different packs.

> Your UI should feel intentional. The icons you ship in it should feel intentional too.
