Devicons ships as framework-native packages plus raw assets. Install whichever one matches your project.

## Package managers

```bash
# React
npm install @devicons/react

# Vue
npm install @devicons/vue

# Svelte
npm install @devicons/svelte

# Icon font + raw SVGs
npm install @devicons/font
```

`pnpm`, `yarn`, and `bun` all work the same way. Swap `npm install` for your preferred tool.

## CDN

Drop the icon font into any HTML page with no build step:

```html
<link
  rel="stylesheet"
  href="https://cdn.devicons.dev/font/devicons.css"
/>

<i class="devicon devicon-react"></i>
```

## Requirements

- Node.js 18.17+ (20.x LTS recommended)
- React 18+ / Vue 3.3+ / Svelte 4+
- Any bundler that handles ESM: Vite, Webpack, Rollup, esbuild, Turbopack

## Verify

Import an icon and render it:

```tsx
import { ReactIcon } from "@devicons/react";

export default function Logo() {
  return <ReactIcon size={32} />;
}
```

If the icon shows up, you're good. Head to the [React guide](/docs/react) for props, tree-shaking, and SSR details.
