`@devicons/vue` exports every icon as a Vue 3 component. Works with `<script setup>`, the Options API, Nuxt, and Vite SSR.

<Note title="Why the underscore suffix?">
Some icon names collide with reserved words. When that happens, the export is suffixed with an underscore: `import { _Vue } from "@devicons/vue";`
</Note>

## Install

```bash
npm install @devicons/vue
```

## Usage

```vue
<script setup lang="ts">
import { ReactIcon, VueIcon } from "@devicons/vue";
</script>

<template>
  <div class="flex gap-3">
    <VueIcon :size="48" />
    <ReactIcon :size="48" mono />
  </div>
</template>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `Number \| String` | `24` | Shortcut for `width` and `height` |
| `mono` | `Boolean` | `false` | Monochrome variant |
| `title` | `String` | `undefined` | Adds an SVG `<title>` for accessibility |
| `color` | `String` | `currentColor` | Fill override for monochrome icons |

## Nuxt

Auto-import icons across your Nuxt app:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ["@devicons/vue/nuxt"],
});
```

## Tree-shaking

Named imports are ESM-first and fully tree-shakeable.

```ts
import { VueIcon } from "@devicons/vue";
```
