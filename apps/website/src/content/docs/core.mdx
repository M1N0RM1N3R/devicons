`@devicons/core` is the foundation. It holds every SVG source file, the icon metadata catalog, and the build tools that the framework packages (`react`, `vue`, `svelte`, `font`) consume at compile time.

You probably don't need to install it directly — the framework packages pull it in as a dependency. But if you're building your own tooling, writing a plugin, or just want raw SVGs without a framework wrapper, this is the package.

<Note variant="info" title="Direct export">
Core re-exports every SVG as a plain string. There's no framework runtime, no virtual DOM, no reactivity — just the markup. If you need an `<svg>` element in a non-framework context (email templates, server-rendered HTML, build scripts), import from core.
</Note>

## Install

```bash
npm install @devicons/core
```

## What's in the box

The package exports three things:

1. **SVG strings** — every icon as a named export containing raw SVG markup.
2. **Metadata** — a JSON catalog with icon names, slugs, tags, and variant info.
3. **Build utilities** — helpers used internally by the framework packages to generate typed components from SVG sources.

## Usage

```ts
import { react, vue, svelte } from "@devicons/core";

// Each export is a plain SVG string
console.log(react);
// → '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 128 128">...</svg>'
```

You can also access the metadata catalog:

```ts
import { metadata } from "@devicons/core";

// Array of icon entries with name, slug, tags, variants
console.log(metadata[0]);
// → { name: "React", slug: "react", tags: ["frontend", "ui"], ... }
```

## When to use core

- You want SVGs without any framework dependency.
- You're building a custom icon component for a framework we don't ship yet.
- You need programmatic access to the icon catalog (search, filtering, code generation).
- You're writing a bundler plugin, Figma plugin, or CLI tool that consumes the icons.

## Exports

| Export | Type | Description |
| --- | --- | --- |
| `[iconSlug]` | `string` | Raw SVG markup for that icon |
| `metadata` | `IconMeta[]` | Full catalog with names, slugs, tags, and variants |
| `slugs` | `string[]` | Flat list of all available icon slugs |
