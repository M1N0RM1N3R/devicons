Devicons ships two variants per icon: a full-color brand mark and a monochrome glyph that inherits `currentColor`. The monochrome variant is the one you style.

## Tint with currentColor

Wrap the icon in an element with a text color. The monochrome variant picks it up.

```tsx
<div className="text-accent">
  <ReactIcon mono size={48} />
</div>

<button className="text-text-muted hover:text-accent transition-colors">
  <GithubIcon mono size={20} />
</button>
```

## Override with the color prop

For a one-off color, pass it directly:

```tsx
<ReactIcon mono color="#ff4d00" size={48} />
```

## CSS custom properties

Hook icons into your design token system:

```css
:root {
  --icon-color: #ff4d00;
}

.icon {
  color: var(--icon-color);
}
```

```tsx
<span className="icon">
  <ReactIcon mono size={48} />
</span>
```

## Dark mode brand colors

Some brands ship different marks for light vs. dark backgrounds. GitHub and Apple are the usual ones. Devicons exposes suffix variants for these:

```tsx
import { GithubIcon, GithubLightIcon } from "@devicons/react";

function ThemedLogo() {
  return (
    <>
      <GithubIcon className="dark:hidden" size={32} />
      <GithubLightIcon className="hidden dark:block" size={32} />
    </>
  );
}
```

## Brand guidelines

Icons tied to strict brand guidelines (Slack, Figma, Google) default to the guideline-approved color. Check the brand's public usage rules before overriding. Most guidelines are linked on the icon's detail page.
