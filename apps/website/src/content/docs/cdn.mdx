Every Devicons package is published to npm, which means every file is reachable through a public npm CDN. Reach for this when you need:

- Quick prototypes and CodePen / JSFiddle demos
- Zero-build legacy stacks (WordPress, Rails, Django templates)
- Loading individual SVGs on demand from static HTML
- ESM imports directly in the browser
- A region-friendly mirror when `npmjs.com` is slow

## Providers

Four public mirrors are supported. Pick the one closest to your audience and the right tool for the file type you need.

### UNPKG

Default for any file. Global CDN, US origin — fastest choice for most demos.

```
https://unpkg.com/<pkg>@<version>/<path>
```

### jsDelivr

Multi-region (US / EU / Asia) with aggressive edge caching. Good balance of speed and availability worldwide.

```
https://cdn.jsdelivr.net/npm/<pkg>@<version>/<path>
```

### npmmirror

China-friendly mirror. Use when UNPKG or jsDelivr is slow or blocked in your target region.

```
https://registry.npmmirror.com/<pkg>/<version>/files/<path>
```

### Skypack

ESM JavaScript imports only — not for CSS, SVG, or font files. Serves pinned, optimized modules you can `import` straight into the browser.

```
https://cdn.skypack.dev/<pkg>@<version>
```

<Note variant="warn" title="Pin a version in production">
`@latest` (or omitting the version entirely) is fine for sandboxes. In production, always pin a semver — unpinned URLs break silently when we ship a new major.
</Note>

## Icon font

Serve `devicons` directly — one `<link>` tag is enough. Skypack is skipped here because it targets JS modules, not stylesheets.

**UNPKG**

```html
<link
  rel="stylesheet"
  href="https://unpkg.com/devicons@1.8.0/css/devicons.min.css"
/>
```

**jsDelivr**

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/devicons@1.8.0/css/devicons.min.css"
/>
```

**npmmirror**

```html
<link
  rel="stylesheet"
  href="https://registry.npmmirror.com/devicons/1.8.0/files/css/devicons.min.css"
/>
```

Then drop an `<i>` anywhere:

```html
<i class="devicon devicon-react"></i>
```

See the [icon font guide](/docs/icon-font) for sizing, color, and the full slug list.

## SVG sprite

The sprite is a single `<svg>` document containing every icon as a `<symbol>`. Reference icons with `<use>` — ideal when many icons render on one page without the bloat of individual requests.

**UNPKG**

```html
<svg class="icon" width="24" height="24" aria-label="React logo">
  <use href="https://unpkg.com/@dev.icons/core@latest/export-files/sprite.svg#react"></use>
</svg>
```

**jsDelivr**

```html
<svg class="icon" width="24" height="24">
  <use href="https://cdn.jsdelivr.net/npm/@dev.icons/core@latest/export-files/sprite.svg#react"></use>
</svg>
```

**npmmirror**

```html
<svg class="icon" width="24" height="24">
  <use href="https://registry.npmmirror.com/@dev.icons/core/latest/files/export-files/sprite.svg#react"></use>
</svg>
```

<Note variant="info" title="Symbol ids match icon slugs">

Every `<symbol>` id in the sprite is the icon slug from the [icon library](/icons):

- `#react`, `#vue`, `#svelte` — base logos
- `#nextjs-icon`, `#postgresql-icon` — glyph-only variants

</Note>

## Raw SVGs via @dev.icons/core

`@dev.icons/core` ships every icon as an individual SVG under `export-files/icons/`. You can fetch, embed, or inline any of them directly — no bundler, no wrapper.

### 1. Inline as `<img>`

Simplest approach, works everywhere.

```html
<img
  src="https://cdn.jsdelivr.net/npm/@dev.icons/core@latest/export-files/icons/react.svg"
  alt="React logo"
  width="48"
  height="48"
/>
```

### 2. Fetch and inject

Pulling the raw markup lets you style the icon with CSS (color, stroke, filters).

```html
<span class="icon" data-icon="postgresql" aria-hidden="true"></span>

<script type="module">
  const BASE =
    "https://cdn.jsdelivr.net/npm/@dev.icons/core@latest/export-files/icons";

  for (const el of document.querySelectorAll("[data-icon]")) {
    const slug = el.getAttribute("data-icon");
    const res = await fetch(`${BASE}/${slug}.svg`);
    el.innerHTML = await res.text();
  }
</script>
```

### 3. Import as ES module (Skypack)

Skypack serves the package as a pinned, optimized ES module — no install, no bundler:

```html
<script type="module">
  import { react, vue, postgresql } from "https://cdn.skypack.dev/@dev.icons/core@latest";

  // Each export is a plain SVG string
  document.getElementById("logo").innerHTML = react;
</script>
```

### 4. Fetch from a build script / server

```ts
// Node 18+ or any modern runtime
const url =
  "https://registry.npmmirror.com/@dev.icons/core/latest/files/export-files/icons/typescript.svg";

const svg = await fetch(url).then((r) => r.text());
console.log(svg);
// '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 128 128">...</svg>'
```

### Icon variants

Most brands ship both a full logo and a glyph-only mark. Append the variant directly to the slug:

| Path | Example |
| --- | --- |
| `icons/<slug>.svg` | `icons/react.svg` |
| `icons/<slug>-icon.svg` | `icons/nextjs-icon.svg` |

Slugs are the same ones listed on the [icon library](/icons).

## Versioning and caching

UNPKG, jsDelivr, and npmmirror all honor semver range URLs:

```
https://unpkg.com/@dev.icons/core@1.2.3/export-files/icons/react.svg
https://cdn.jsdelivr.net/npm/@dev.icons/core@^1/export-files/icons/react.svg
https://unpkg.com/@dev.icons/core@latest/export-files/icons/react.svg
```

<Note variant="tip" title="Cache behavior">

- **Pinned** (`@1.2.3`) — immutable, cached forever at the edge. Always use in production.
- **Range** (`@^1`) — revalidated periodically; picks up patches and minors automatically.
- **`@latest`** — drifts with every release. Fine for demos, risky in production.

</Note>

## When CDN is not enough

- You need tree-shaken, typed components → use [`@dev.icons/react`](/docs/react), [`@dev.icons/vue`](/docs/vue), or [`@dev.icons/svelte`](/docs/svelte).
- You need programmatic metadata (tags, variants, search) → install [`@dev.icons/core`](/docs/core) locally.
- You want SSR-rendered markup without a runtime → [`@dev.icons/core`](/docs/core) exports each icon as a plain SVG string.
