This guide assumes you already have a React, Vue, or Svelte project running. If not, start with [Installation](/docs/installation).

## 1. Install

```bash
npm install @devicons/react
```

## 2. Import and render

```tsx
import { ReactIcon, VueIcon, SvelteIcon } from "@devicons/react";

export default function Stack() {
  return (
    <div className="flex gap-4">
      <ReactIcon size={48} />
      <VueIcon size={48} />
      <SvelteIcon size={48} />
    </div>
  );
}
```

Every icon is a named export. The component name is PascalCase + `Icon`, so `next-js` becomes `NextJsIcon`.

## 3. Switch to monochrome

Full-color icons are the default. Add the `mono` prop to get a single-color variant that inherits `currentColor`.

```tsx
<div className="text-accent">
  <ReactIcon size={48} mono />
</div>
```

## 4. Make it interactive

Icons accept every SVG attribute: `onClick`, `aria-label`, `role`, and so on.

```tsx
<button
  type="button"
  aria-label="View on GitHub"
  className="text-text-muted hover:text-accent transition-colors"
>
  <GithubIcon size={24} mono />
</button>
```

## That's it

You're shipping Devicons. Browse the [icon library](/search) for the full catalog, or read the [React guide](/docs/react) for props, tree-shaking, and SSR.
