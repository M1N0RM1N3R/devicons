`@devicons/font` is the no-framework option. One CSS file, 1,600+ glyphs. Works in legacy stacks, email templates, or plain HTML.

<Note title="Class prefix">
All classes use the `devicon-` prefix to avoid collisions. Add `.devicon` to opt into the font, then `.devicon-<slug>` to pick a glyph, e.g. `devicon-react`, `devicon-next-js`.
</Note>

<Note variant="info" title="Version numbering">
The font package has a higher version number (`>1.x`) than the framework packages. The icon font predates the framework wrappers and has its own release history. Icon content is identical across all packages at any given release.
</Note>

## Install

```bash
npm install @devicons/font
```

For a no-build workflow, see the [CDN guide](/docs/cdn).

## Usage

```html
<i class="devicon devicon-react"></i>
<i class="devicon devicon-vue"></i>
<i class="devicon devicon-svelte"></i>
```

Slugs match the icon IDs in the [icon library](/search).

## Sizing and color

The font inherits `font-size` and `color`.

```html
<i
  class="devicon devicon-github"
  style="font-size: 32px; color: #ff4d00;"
></i>
```

## Ligatures

Ligatures are disabled to keep the bundle small. Use the [React](/docs/react) or [Vue](/docs/vue) packages if you need component-based rendering.
