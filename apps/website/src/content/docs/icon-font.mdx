`@devicons/font` is the no-framework option. One CSS file, 1,600+ glyphs — drop it into legacy stacks, email templates, or a static HTML page and you're done.

<Note title="Class prefix">
Every class is namespaced under `devicon-`. That's on purpose: a bare `.react` or `.vue` selector would collide with just about every stylesheet in the wild, so we reach for the `devicon-` prefix to stay out of the way. Use the parent `.devicon` class to opt into the font, then `.devicon-<slug>` to pick a glyph — e.g. `devicon-react`, `devicon-next-js`.
</Note>

## Install

```bash
npm install @devicons/font
```

Or link from a CDN:

```html
<link
  rel="stylesheet"
  href="https://cdn.devicons.dev/font/devicons.css"
/>
```

## Usage

```html
<i class="devicon devicon-react"></i>
<i class="devicon devicon-vue"></i>
<i class="devicon devicon-svelte"></i>
```

Slugs match the icon IDs shown in the [library](/).

## Sizing and color

The font inherits `font-size` and `color` — style it like any text.

```html
<i
  class="devicon devicon-github"
  style="font-size: 32px; color: #ff4d00;"
></i>
```

## Ligatures

Ligatures are disabled to keep bundle size small. If you need them, use the [React](/docs/react) or [Vue](/docs/vue) packages instead.
