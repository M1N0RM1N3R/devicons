`devicons` is the no-framework option. One CSS file, 1,600+ glyphs. Drop it into legacy stacks, email templates, or a plain HTML page.

<Note title="Class prefix">
Every class is namespaced under `devicon-`. A bare `.react` or `.vue` selector would collide with most stylesheets, so the prefix keeps things safe. Use `.devicon` to opt into the font, then `.devicon-<slug>` to pick a glyph, e.g. `devicon-react`, `devicon-next-js`.
</Note>

<Note variant="info" title="Version numbering">
The font package uses a higher version number (`>1.x`) than the framework packages. This is intentional: the icon font predates the framework wrappers and carries its own release history for backwards compatibility. The icon content is identical across all packages at any given release.
</Note>

## Install

```bash
npm install @devicons/font
```

Prefer a no-build workflow? See the [CDN guide](/docs/cdn) for stylesheet, sprite, and raw-SVG URLs.

## Usage

```html
<i class="devicon devicon-react"></i>
<i class="devicon devicon-vue"></i>
<i class="devicon devicon-svelte"></i>
```

Slugs match the icon IDs in the [icon library](/search).

## Sizing and color

The font inherits `font-size` and `color`. Style it like any text.

```html
<i
  class="devicon devicon-github"
  style="font-size: 32px; color: #ff4d00;"
></i>
```

## Ligatures

Ligatures are disabled to keep bundle size small. If you need them, use the [React](/docs/react) or [Vue](/docs/vue) packages instead.
