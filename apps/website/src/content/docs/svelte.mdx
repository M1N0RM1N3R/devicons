`@devicons/svelte` ships native Svelte components. SvelteKit, Vite, and Astro integrations all work without extra config.

<Note title="Why the underscore suffix?">
Some icon names collide with reserved words. When that happens, the export is suffixed with an underscore: `import { _Svelte } from "@devicons/svelte";`
</Note>

## Install

```bash
npm install @devicons/svelte
```

## Usage

```svelte
<script lang="ts">
  import { SvelteIcon, ReactIcon } from "@devicons/svelte";
</script>

<div class="flex gap-3">
  <SvelteIcon size={48} />
  <ReactIcon size={48} mono />
</div>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `number \| string` | `24` | Width and height shortcut |
| `mono` | `boolean` | `false` | Monochrome variant using `currentColor` |
| `title` | `string` | `undefined` | Accessible label |
| `color` | `string` | `currentColor` | Fill override for monochrome variants |

## SvelteKit

No special config needed. Import inside any `+page.svelte`, `+layout.svelte`, or component file.

```svelte
<script lang="ts">
  import { GithubIcon } from "@devicons/svelte";
</script>

<a href="https://github.com" aria-label="GitHub">
  <GithubIcon size={24} mono />
</a>
```
