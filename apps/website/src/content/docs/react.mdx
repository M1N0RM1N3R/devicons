`@devicons/react` ships every icon as a named export. All components are fully typed, tree-shakeable, and zero-runtime.

<Note title="Why the `_` suffix?">
Some icon names conflict with reserved words in JavaScript or within a framework. In order to use `React` the export names are suffixed with an underscore, as in `import { _React } from "@dev.icons/react";`. 
</Note>

## Install

```bash
npm install @devicons/react
```

## Usage

```tsx
import { ReactIcon } from "@devicons/react";

export function Logo() {
  return <ReactIcon size={32} />;
}
```

## Props

Every icon accepts the standard SVG props plus these extras:

| Prop      | Type                    | Default     | Description                                              |
| --------- | ----------------------- | ----------- | -------------------------------------------------------- |
| `size`    | `number \| string`      | `24`        | Sets both `width` and `height`.                          |
| `mono`    | `boolean`               | `false`     | Renders the monochrome variant using `currentColor`.     |
| `title`   | `string`                | `undefined` | Accessible name. Rendered as an SVG `<title>` element.   |
| `color`   | `string`                | `currentColor` | Override color for monochrome variants.               |

Any other prop — `className`, `onClick`, `aria-*`, `data-*` — is forwarded to the root `<svg>` element.

## Tree-shaking

Named imports are the secret. Avoid wildcard imports — they defeat tree-shaking in most bundlers.

```tsx
// Good — only ReactIcon lands in your bundle
import { ReactIcon } from "@devicons/react";

// Avoid — pulls the whole catalog
import * as Devicons from "@devicons/react";
```

## SSR & React Server Components

All icons are pure — no `useState`, no `useEffect`. They work inside React Server Components, Next.js `app/` routes, Remix loaders, and any SSR setup with zero config.

```tsx
// app/page.tsx
import { ReactIcon } from "@devicons/react";

export default function Page() {
  return <ReactIcon size={64} />;
}
```

## Accessibility

Icons are decorative by default (`aria-hidden="true"`). When an icon conveys meaning, pass a `title`:

```tsx
<ReactIcon title="React" size={24} />
```

For icon-only buttons, prefer `aria-label` on the button itself:

```tsx
<button aria-label="Open React docs">
  <ReactIcon size={20} mono />
</button>
```
